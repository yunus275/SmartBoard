# Aymen Schoolboard

A plain website - nothing to install or build.

## Put it online
1. github.com > New repository > upload everything from this folder > Commit.
2. vercel.com > Add New > Project > pick the repository > Deploy.
   (Vercel serves the `dist/` folder. No build step.)

## Change the app later
Replace `src/app.html` and `dist/index.html` with the new file (same content), then commit.

## Windows app
Use the separate *Windows Installer* ZIP: double-click Install.bat, no Node.js needed.
